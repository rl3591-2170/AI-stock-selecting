# 知条件 · 自然语言选股实验室

同花顺校招题目「自然语言智能选股与策略解释器」的可操作 Web MVP。

- 产品：https://stock-lens-strategy-lab.ruoshuilei.chatgpt.site/ （当前保持所有者访问；评审前需设置访问范围）
- 源码：https://github.com/rl3591-2170/AI-stock-selecting
- 提交清单：[docs/submission/提交清单.md](docs/submission/提交清单.md)

## 用户、任务与设计

面向按自己研究思路筛选A股的个人研究者。流程：选择基本面、趋势或交集 → 描述意图/编辑条件 → 澄清定义 → 确认增量修改 → 执行 → 查看入选/排除/未知依据 → 比较、保存、导出。

两套条件独立保留，行业范围共用；每组最多24条AND条件。没有隐藏综合评分，不自动放宽零结果条件。

- **基本面**：营收/归母净利润同比、正盈利、PE/PB、市值；加载扶摇后支持ROE和资产负债率。
- **趋势**：MA20/60关系、均线方向、价格偏离、3/5/10/20日变化、回撤、成交量比、前高距离、区间宽度、波动率。提供趋势回调、放量越过前高、整理接近前高、近一月趋势四个可编辑起点，关注3–10交易日研究。
- **交集**：同时满足两组条件。
- **机构披露**：数据页可加载完整20个交易日龙虎榜机构席位，用上榜天数筛选；不把它称为全市场机构活跃度。
- **解释和复核**：上下限冲突阻断、同向重复消除、偏好取舍提示、实际值、只差一项、条件瓶颈、修改前后名单变化、个股60日图、三股比较、保存最多20条策略、JSON导出。

## AI、确定性代码与用户确认

明确语法（如“PE上限设为20”）由本地解析器处理并明确标注。复杂自由描述使用真实DeepSeek `deepseek-v4-pro`；输入、当前规则及最多8条对话发送至配置供应商。采用非思考模式和JSON输出，45秒超时；遵循[官方接口说明](https://api-docs.deepseek.com/api/create-chat-completion/)。

模型负责澄清和提出完整Plan，不产生股票数字或直接执行代码。服务端校验指标白名单、行业、组别、运算符、有限数值、唯一ID和回复结构。未解决的问题或不支持要求不能作为方案自动执行。用户采用方案仅改编辑区，点击执行才更新名单。

单期同比不能验证增长持续性；复杂请求超出数据能力时必须说明。模型异常时保留原规则。收益保证/内幕/操纵请求拒绝。不提供买卖时点或确定收益。

2026-10-05实际核验：真实模型返回模糊意图澄清，并说明持续增长缺少多期数据；自由表达“最低要求设为百分之五”返回两项同比≥5%的完整方案，保留其他规则。详见[AI记录](docs/AI_LOG.md)。

## 数据、时点与证据

固定30只手工选取的A股研究样本，行情/估值基准2026-09-30、财务2026H1。不是全市场、指数成分或推荐名单。

页面初始使用已留存的公开备用快照，点击“加载扶摇主源”后按两路并发获取30只，全部通过日期/字段校验才原子切换。失败不静默混源，显示失败股票并保留原快照。数据页、结果顶部和个股条件显示实际来源。

| 数据 | 来源与处理 |
| --- | --- |
| 财务主源 | 扶摇2026H1及2025H1利润表，筛掉披露晚于基准日的记录；营业收入/归母净利润和同比由原始值计算；ROE、资产负债率取同报告期指标 |
| 趋势主源 | 扶摇前复权日线，2026-01-01至基准日；验证OHLCV、非重复日期、窗口长度及最后日期，代码计算技术指标 |
| 历史估值 | 东方财富指定基准日PE/PB/市值；不将扶摇最新估值冒充历史估值 |
| 公开备用数据 | 东方财富累计营业总收入/归母净利润、腾讯证券前复权日线；营收口径与扶摇营业收入不同，尤其金融行业须核对 |
| iFinD | 个股详情通过MCP获取财务补充原始证据，保留单位和期次，不自动覆盖主源数字 |
| 机构披露 | 扶摇2026-09-02至09-30共20交易日机构榜，逐日验证；仅range_days=1，按日期去重。完整覆盖后未见记录为0天；净额占比缺少成交金额时仍未知 |

实际批量核验：30/30股票的财务、日线成功；20/20机构榜日期成功，共756条原始记录，其中573条当日榜。固定30只样本此窗口均未见当日机构榜记录，不能据此推断没有机构交易。茅台ROE、营收同比、归母净利润同比已与iFinD一致核对。

公开备用快照位于`public/data/snapshot.json`，原始记录和URL在`public/data/evidence/`。授权数据仅运行时加载、可在详情下载，不提交到公开源码。回执保留来源URL、抓取时间、request_id、原始响应；导出保留当前数值和条件。

技术指标口径：当日量的20日均量分母排除当日；近3日与此前20日两个量能窗口不重叠；此前20日高点排除当日。MA、波动率和回撤从真实序列计算，缺失不补零，非正PE/PB不当作便宜。

## 本地运行

Node.js 22.13+（开发验证为24），保留锁文件。

```sh
npm ci
npm run dev
node --experimental-strip-types --test tests/*.test.ts tests/*.test.mjs
npx tsc --noEmit
npm run build
```

不配置密钥也可操作公开备用数据、本地明确语法、手动筛选。带密钥完整运行：

```sh
node scripts/with-credentials.mjs npm run dev
node scripts/with-credentials.mjs node --experimental-strip-types scripts/verify-connections.ts
node scripts/verify-web.mjs
node scripts/verify-model.mjs
```

本地凭证在仓库外0600 JSON文件，默认`~/Documents/Codex/.stock-lens-secrets/credentials.json`，或用`STOCK_LENS_CREDENTIALS_FILE`指定。变量名：`LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`、`HITHINK_FINANCE_API_KEY`、`IFIND_API_TOKEN`。开发启动时仅将这些变量注入本地服务端绑定；构建不含变量值。生产使用Sites秘密环境变量。不要把密钥写入源码、前端、命令参数或Git。

## 边界与未做事项

1. 非实时、非全市场；前复权及财报历史可能修订，不是严格历史时点数据库，不直接支持无前视偏差回测。
2. 每组AND条件，不支持OR/嵌套/自由公式；行业是样本已有行业，不能代替概念题材。
3. 板块主线、连续强势排名、全成分上涨占比、成交额集中度尚未完成，保持未知，不从30只股票外推。净利润现金含量单位未核验，不启用。
4. 龙虎榜覆盖只代表披露记录；当日机构净买入占比仅在分子/分母有效且不冲突时可得，未上榜保持未知。
5. 股票比较、策略保存已实现；无收益回测、跨设备账户、实时监控或下单。
6. 机构接口缓存、主源一小时进程缓存不等于持久生产配额；公开访问前需限制调用额度或设置评审范围。
7. 评审访问范围和候选人独立公告抽查需在提交前确认。当前保留站点已有所有者访问权限。
