# 知条件 · 自然语言选股实验室

同花顺校招题目「自然语言智能选股与策略解释器」的可交互 Web MVP。

## 当前状态

已实现真实快照筛选、可修改条件、冲突校验、入选/排除/待验证解释、原始证据钻取、条件变化对比、最多三家公司比较、浏览器内策略保存及结果 JSON 导出。

**模型适配接口已实现，但尚未配置或验证用户的真实模型服务。** 未配置时返回明确错误；预设示例始终标注为示例，不冒充 AI 输出。当前版本不应作为完整 AI 主链路已经验收的最终提交。

## 目标用户与产品选择

面向能表达研究意图、但不熟悉数据筛选条件的个人研究者。用户输入「经营改善、估值合理、走势稳定」，产品提出可解释定义，让用户检查和修改后再执行；不提供买卖建议或收益预测。

最小闭环：描述意图 → 解释与澄清 → 用户确认条件 → 确定性筛选 → 查看入选/排除证据 → 修改阈值查看名单变化 → 比较或保存。

## 模型配置

模型必须在服务端配置三个环境变量：

| 环境变量 | 含义 |
| --- | --- |
| LLM_BASE_URL | OpenAI兼容接口前缀，例如供应商提供的 `/v1` 地址 |
| LLM_MODEL | 供应商控制台实际 model ID，不猜测营销名称 |
| LLM_API_KEY | 服务端密钥，禁止提交、写入前端或日志 |

本地将 `.env.example` 复制为被Git忽略的 `.env.local`，自行填写。托管时在服务端秘密配置中设置。默认示例中的 DeepSeek 地址不是对用户服务商的确认。

请求调用 `/chat/completions`。模型仅输出白名单指标、运算符、阈值、假设和澄清问题。服务端校验JSON、指标和冲突。25秒超时。模型未配置、响应失败或格式无效不会执行新筛选。自由输入只会送往配置的模型服务，不发送浏览器已保存的策略。

## AI、引擎与数据的分工

- AI：意图解析、提出操作化定义、明确歧义与不支持的要求。
- 用户：检查解释、调整规则、确认执行。
- 引擎：仅支持1–12条 AND 条件，指标白名单，无动态SQL或代码执行。负责比较、三态判断与结果差异。
- 数据：提供字段值和留存证据，模型不能生成股票名单或数值。

## 数据来源及统计口径

当前版本是**30只手工选取A股的固定研究快照**，不是指数成分、全市场或推荐名单。估值与行情基准日为2026-09-30；财务为2026年上半年累计。

- 财务：东方财富公开 `RPT_DMSK_FN_INCOME`，保留报告期、披露日与原始字段。
- 估值：东方财富公开 `RPT_VALUEANALYSIS_DET` 的指定交易日记录。
- 行情：腾讯证券公开前复权日线，取基准日前最后61个收盘价，得到60个简单日收益率。
- 波动率：样本标准差 × √252 × 100；区间最大回撤：峰值到后续低点的最大跌幅，取正数。
- 增长率沿用来源接口字段，未声称已逐家公司与公告全文交叉核验。
- 未获得扶摇/iFinD权限，因此使用公开替代数据，未宣称已接入指定平台。

`public/data/snapshot.json` 为标准化数据；`public/data/evidence/{代码}.json` 为留存原始记录和请求URL；`scripts/fetch-market-data.py` 可重新获取。脚本抓取失败保留缺失与错误，不补造数据。公开接口没有稳定性承诺；重新采集可能得到修订后的结果，需升级数据版本并复核。

来源示例：
- https://data.eastmoney.com/bbsj/
- https://stockapp.finance.qq.com/mstats/
- 公司披露核验入口：https://www.cninfo.com.cn/

## 关键边界

1. 固定历史快照，不是实时行情。数据页面展示期次、基准日、抓取时间和来源。
2. 非历史时点数据库。来源可能后续修订，前复权序列也可能变化；不支持用此快照做历史回测。披露日晚于基准日的财务记录不参与筛选。
3. 负或零PE/PB为口径不适用；缺失不视为0。AND中任一条件确定不符即可排除，但仍保留其他条件的未知状态。
4. 跨行业PE、利润增速不能直接代表投资价值。低基数、亏损、停牌跨日收益等影响可比性。
5. 保存仅在当前浏览器，最多12条策略；不跨设备同步。导出保存规则、结果与数据版本。
6. 暂不支持OR、复杂嵌套、行业中位数、自由时间窗、全市场覆盖、实时监控及回测。模型应明确报告不支持项，禁止静默近似。
7. 未做生产级持久限流与账户配额；本版本先用于私有展示。正式公开模型端点前应增加配额/滥用控制。
8. 拒绝部分明确违规请求，并约束模型输出；关键词检查不是完整的自然语言安全系统。

## 源码结构

- `app/page.tsx`：交互工作台。
- `app/api/interpret/route.ts`：服务端模型适配与校验。
- `lib/screener.ts`：规则定义、校验、三态筛选和变化对比。
- `scripts/fetch-market-data.py`：真实数据获取与计算。

- `docs/TESTING.md`：验证范围、结果和待测项。
- `docs/AI_LOG.md`：实际AI使用与修正记录。
- `docs/DEMO.md`：120秒演示脚本（不是已经录制的视频）。
