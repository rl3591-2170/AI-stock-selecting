# 知条件 · 自然语言选股实验室

同花顺校招题目「自然语言智能选股与策略解释器」的可交互 Web MVP。

## 当前实现与验收状态

本地第三版实现两套独立可编辑规则：基本面、趋势，以及两者交集。行业范围共用；筛选均为透明的 AND 条件，不采用未经解释的综合评分。

已实现：明确语法增量修改、多轮澄清选项/范围追问、上下限冲突、重复规则消除、偏好取舍提示、变更确认、入选/排除/待验证、只差一项、条件瓶颈统计、原始证据、60日价格与MA20/MA60图、三股比较、策略保存和JSON导出。

**真实模型服务和扶摇/iFinD已配置凭证，但尚未完成认证与取数验证。** 本地明确语法解析会标注身份，复杂自由描述需真实模型。模拟模型测试只验证接口机制，不证明模型理解质量。本版本不能声称全市场覆盖、实时选股或完整AI链路验收。

2026-10-05：用户已提供DeepSeek、扶摇、iFinD凭证；Sites服务端秘密配置已保存。真实请求均因网络限制失败，不能判断认证是否有效。构建与自动化验证通过；当前环境的本地监听报EPERM、源仓库域名解析失败，第三版尚未浏览器验收及发布。原线上地址仍是前一版。后续发布后须更新此状态。

## 目标用户与核心设计

面向按自己研究思路筛选A股的个人研究者。用户可以从基本面、短期量价或两者交集出发，不必接受一套固定投资风格。

流程：选择思路 → 描述或编辑条件 → 澄清定义 → 检查增量变更 → 采用到编辑区 → 执行筛选 → 查看入选和排除证据 → 修改、比较、保存。

- 基本面：收入增长、归母净利润增长和正盈利、PE/PB、市值。ROE、资产负债率和现金质量尚待接入。
- 趋势：MA20/MA60关系、均线方向、价格偏离、3/5/10/20日涨跌幅、距高点回撤、成交量相对历史均量、距此前20日高点、区间宽度及历史波动。关注3–10个交易日研究，但不预测持有收益。
- 交集：严格同时满足两组条件；模板切换仅替换趋势组。
- 行业：当前仅固定样本已有行业，不能用行业替代概念题材。
- 板块强弱、持续强势天数、成交额集中度、机构席位披露：定义已进入字典和编辑器，数据缺失时未知，不伪造热点和机构参与。

## AI、规则与确认边界

明确语法由本地解析器执行，例如「PE上限设为20」「均线距离在-3到3之间」「删除PE」。未提及的规则保留。含糊目标先提问，支持选择选项和继续填写范围；部分无法理解时不部分应用。

真实模型负责更复杂的自由描述。服务端传入指标白名单、当前两套规则、行业目录、最近对话，校验模型完整计划和澄清结构。不会把用户描述变成任意SQL/可执行代码。出现超时、异常、未知字段或未解决问题时不修改计划。

用户采用proposal只修改编辑区；点击执行才更新结果。逻辑冲突阻断，重复项可移除较宽条件；偏好取舍是提示，不伪装成绝对冲突。参数是示例或用户选择，不是回测优化结论。

服务端变量：

| 变量 | 用途 |
| --- | --- |
| LLM_BASE_URL | 实际供应商提供的OpenAI兼容接口前缀 |
| LLM_MODEL | 控制台确切模型ID，不根据营销名称猜测 |
| LLM_API_KEY | 模型密钥，只在服务端 |
| HITHINK_FINANCE_API_KEY | 扶摇密钥，只用于服务端/本地取数 |

本地复制`.env.example`到被忽略的`.env.local`。密钥不得提交Git、进入前端或写入日志。模型接口25秒超时；请求会发送输入、当前规则与最多8条历史消息至配置供应商。

## 数据与证据

当前固定快照：30只手工选取A股，2026-09-30行情/估值、2026H1财务。不是指数成分、全市场或推荐名单。

- 东方财富公开 `RPT_DMSK_FN_INCOME`：保留期次、披露日和原始财务字段。
- 东方财富公开 `RPT_VALUEANALYSIS_DET`：指定基准日估值。
- 腾讯证券前复权日线：每股留存181个观测日；趋势计算使用完整留存序列，图表展示末60日，MA60有足够前置历史。
- `public/data/snapshot.json`：标准化指标，版本`snapshot-20260930-v3`。
- `public/data/evidence/{代码}.json`：原始响应和请求URL。
- `scripts/fetch-market-data.py`：公开源获取；`scripts/enrich-trends.py`：从原始留存数据重算技术指标。

均线均用前复权收盘。今日量/此前20日均量的分母排除今日；最近3日均量/此前20日均量的两个窗口不重叠；此前20日高点排除当日。近3日缩量不单独等于回撤阶段缩量，需与价格条件联合检查。详细公式在页面字典及`lib/screener.ts`。

来源可能修订，前复权基准可能变化。当前数据不构成历史时点数据库，不能直接用来回测。披露日晚于快照日的财务不参与。复权价格不是下单价。技术窗口按观测日，停牌可能与完整交易日历不一致。

## 扶摇主源与iFinD补充的接入准备

两项本地技能已安装，但不等于网站已有数据权限。

`lib/providers/fuyao.ts`已实现公开REST契约适配：代码消歧、前复权日线、财务指标、机构榜、行业/概念目录；HTTP200仍必须检查业务code，有限重试并保留request_id，未知不补零。

拿到密钥后可先运行小样本验证（不替换网站快照）：

```sh
node --env-file=.env.local --experimental-strip-types scripts/check-fuyao.ts
```

记录保存在被Git忽略的`work/provider-checks/`，包含原始证据，无认证头。需进一步核对单位、披露时点、与现有源差异、板块和机构权限，才能批量同步并切换版本。不得把扶摇“净利润同比”未经核验映射为“归母净利润同比”。资金流接口文档注明客户端专用，API Key不自动赋予Web调用权限。

iFinD使用已提供的MCP个人中心Token，先按官方工具名进行小样本查询，异常时再核对工具权限。已实现网站服务端MCP传输、握手及原始补充证据查询，但未验证真实响应。个股详情可主动查询授权证据，失败会明确显示且不改变筛选快照。

## 已知边界与未做事项

1. 各组最多24条AND条件；不支持OR、嵌套条件、自由指标公式。
2. 非正PE/PB为不适用；缺失为未知。任何确定失败可排除，但未知项仍展示。
3. 行业/概念主线需完整目录、指数与成分；30只样本不能外推全市场热度。机构席位只代表龙虎榜披露，不代表所有机构交易。
4. 20日个股走势不等于一个月主线题材；未做收益回测、实时监控、下单或收益承诺。
5. 浏览器保存最多20条，不能跨设备；导出包含已执行规则、原始数值、数据版本与边界。
6. 无生产级持久限流/账户配额。真实模型端点公开前应增加配额控制。
7. 新UI尚待真实浏览器验收；模型尚待真实调用；凭证就绪后才能验收完整AI及指定数据源主链路。
