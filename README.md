# 知条件 · 自然语言选股与策略解释器

把研究思路变成可检查、可修改、可执行的条件，再用真实数据解释每只股票为什么入选、排除或待验证。面向希望保留自己判断、需要重复筛选 A 股的投资者。本产品用于研究，不提供买卖指令或收益承诺。

- 网站：https://stock-lens-strategy-lab.ruoshuilei.chatgpt.site/
- 源码：https://github.com/rl3591-2170/AI-stock-selecting
- 网站当前仅所有者可访问；提交评审前需由所有者设置评审访问权限。

## 怎么用

1. 打开页面，自动从扶摇读取50只研究样本的最新可用数据；进度和失败原因可见。
2. 选择「价值与基本面」「波段（3–7个交易日）」或「两者交集」。
3. 在统一「板块范围」选择行业或题材，多选取并集；规则之间取交集。
4. 用自然语言描述或直接改条件。遇到含糊词先澄清，预览修改、冲突、缺失数据和名单变化。
5. 「采用修改」只改变编辑区；「执行筛选」更新结果。可撤销、比较三家公司、保存到浏览器、导出条件和证据。
6. 在详情核对字段实际值、公式、时间和扶摇回执；按需调用 iFinD 补充财报证据。

## 两套模型

价值与基本面：营收增长、ROE、资产负债率、现金利润比、PE/PB/PS，以及 MA20/60、20日涨跌、60日风险等中期观察。财务指标采用报告期累计口径，不能把半年 ROE 直接当全年。

波段：MA5/10方向与距离、近3日真实上穿、5日平台突破、5日回撤/整理、成交量相对历史均量、ATR/RSI、收盘位置及近5日机构披露。3–7日是研究窗口，不是预测持仓期限。20日均量或14日 ATR 是衡量当前信号的统计基准，不代表要求持仓20天。

可修改模板只是研究起点，不是回测优化后的策略。行业和题材在分类上仍有区别，但入口统一；题材标签不是实时热点或龙头排名。50只手工研究样本覆盖传统公司及商业航天、半导体、PCB、CPO、存储、光伏、核聚变、机器人、灵巧手、脑机接口和创新药，不能代表全市场。

## AI 与工程化

DeepSeek 负责自由表达到结构化规则、歧义澄清和修改解释；明确语法优先走本地编译。模型不会生成股票实际数值或自行执行筛选。

代码负责字段/分组/单位白名单、有限数值、运算符、数量限制、板块并集、部分明确语义边界、上下限冲突、重复条件、偏好取舍、物理取值范围、缺失数据、规则版本和确定性执行。提案携带请求编号与阶段记录；旧规则版本上的提案不能直接采用。记录可随结果导出。API失效、模型超时/格式错误、语义校验失败均不改变现有规则。

多轮澄清保留同一请求的其他条件。自然语言准确率不是100%；有些明确语义可由代码拦截，但复杂自由表达仍需用户检查条件预览。未提供在线学习、模型微调或通用金融 Agent。

## 数据与时间

**产品运行时数值只从扶摇取得；iFinD 作为独立补充。已取消东方财富/腾讯静态快照作为产品数据和降级回退。**

- 扶摇 REST：前复权日线、最新报价、最新估值、利润表、现金流量表、财务指标、机构龙虎榜。
- iFinD MCP：按所选股票及报告期查询财务证据。本地已验证；本次线上补充查询遇到HTTP522连接超时，未声称稳定可用，主源筛选不受影响。原始响应不自动覆盖主源，避免未核对单位/口径就混用。
- 代码派生：均线/上穿、涨跌、回撤、量能、ATR/RSI、现金利润比等；原字段、公式、日期逐项保留。
- 日线筛选使用最新完整收盘日。报价和估值显示各自上游批次时间，不把批次时间声称为每只股票逐笔时间。
- 财务逐股选择截至筛选日已披露的最新报告期，保留报告期与披露日期。财报和复权历史可能修订，不是严格历史时点数据库。
- 首次打开及手动刷新拉取最新数据；不是逐笔流式行情。市场批次缓存约60秒，单股数据短时缓存5分钟。
- 缺失值保留未知，逐股取数失败不填0；初始化失败可保留上次已取得的官方数据及原时间。
- 机构指标仅在逐日完整覆盖后计算；未上榜不等于没有机构参与。

受限授权数据与密钥不进入公开源码或构建静态资源。运行时回执供授权访问者核验、下载。`tests/fixtures` 中旧公开快照仅用于回归测试，不被产品加载或部署为数据文件。

## 启动与验证

Node.js 24，npm：

```sh
npm ci
cp .env.example .env.local
# 在本地环境文件填入自己的授权值，禁止提交
npm run dev
node --experimental-strip-types --test tests/*.test.ts tests/*.test.mjs
npx tsc --noEmit
npm run build
```

所需变量见 `.env.example`：`LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`、`HITHINK_FINANCE_API_KEY`、`IFIND_API_TOKEN`。服务端调用，前端没有密钥。`scripts/with-credentials.mjs` 是本机外置密钥注入工具，换机器请用自己的环境配置。

真实接口验证：运行开发服务后执行 `node --experimental-strip-types scripts/verify-v5.ts`（50股主源与模型案例），或 `scripts/check-v5-workflow.mjs`（带断言的模型语义检查）。这些调用消耗实际供应商额度，回执存于忽略的 `work/`，不提交。

历史抓取/增强脚本及旧测试只用于复现旧版本，不能替代 v5 官方运行时数据链路。

## 已知边界与未做

无全市场扫描、分钟线、下单、回测、收益预测、自动监控；无可验证的实时热点排名、板块全量广度/资金集中度。部分字段如扣非利润、市值尚未取得匹配口径，保持待验证。连续多个季度增长不能用单期同比冒充。部分财务期次/单位存在跨公司差异，详情中需核对。策略仅保存在当前浏览器。每次加载50股有取数等待，当前用有限并发控制上游压力。
