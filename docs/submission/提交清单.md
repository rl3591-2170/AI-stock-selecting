## 提交说明

产品名称：知条件。

让用户把基本面或短期趋势研究思路转为可检查、可修改的条件，展示真实实际值、排除原因和未知信息。模型提出定义和修改方案，用户确认后由确定性代码筛选。基本面与趋势独立，交集要求同时满足。采用固定历史研究样本，不声称全市场、实时或收益有效性。

体验顺序：打开工作台 → 加载扶摇主源 → 选择基本面/趋势/交集 → 描述或编辑 → 采用并执行 → 查看排除及证据 → 比较/保存。数据页可另行加载20日机构披露。
