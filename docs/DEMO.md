# v4 演示脚本（约150秒，视频尚未录制）

1. 0–20秒：解释目标用户与流程。50只研究池，11题材，不是全市场。基本面默认看营收成长、归母净利率、扣非占比、估值；点击“研究范围”勾选PCB或半导体。
2. 20–45秒：输入“只看半导体或PCB，PE不超过80”。解释题材取并集，数值AND；提案先显示差异，采用后进入草稿，执行才改变结果。
3. 45–75秒：切换趋势。展示MA10方向、MA5距离、量能、ATR；切换“近日上穿5日线”，说明上穿事件与站上位置不同。指标库搜索RSI，阈值可以自己改。
4. 75–105秒：输入“只看存储，更稳一点，机构活跃度在2和5之间”。依次选择价格波动与机构上榜天数；所有要求保留，机构未加载仍未知，不能伪造0。展示冲突时不能执行，撤销恢复。
5. 105–130秒：加载扶摇主源（可在演示前完成缓存），展示50/50核验。打开个股逐项实际值、MA周期、公司题材依据和原始证据；iFinD作补充。
6. 130–150秒：说明模型只负责语言到规则，确定性代码算指标与名单。展示四项真实模型案例及发现并修正OR/AND的验证记录。保存策略或比较公司。说明当前是固定历史快照、无收益回测、不保证预测。

录制前确认评审可访问范围。不要将未录制视频写为已提交；不要把小样本模型验证称为百分百准确。
