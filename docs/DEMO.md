# 150秒演示脚本（题目02视频可选）

录制前打开页面完成官方取数，保证展示数据与时间；不要把历史录制的名单描述成当日必然名单。

1. 0–20秒：展示价值与基本面、3–7日波段、交集。说明50只研究样本，统一板块可多选，不是全市场。
2. 20–50秒：输入“只看半导体或PCB，PE不超过80”。展示结构化范围和条件、预计影响；采用后执行。
3. 50–80秒：输入“更稳一点”。选择价格波动或财务负担，展示澄清后增量修改，其他条件保留。再演示矛盾边界被拦截。
4. 80–110秒：切换波段，使用5日平台/回踩模板。打开排除股票，核对实际值、公式、日线日期和财务期次。
5. 110–135秒：打开数据与口径：扶摇主源、iFinD独立补充、报价批次与收盘日不同；展示缺失未知。
6. 135–150秒：比较/保存/导出，说明AI负责理解、代码负责计算和校验，规则与数据可追溯。没有收益回测或交易指令。
