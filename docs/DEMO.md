# 第三版演示脚本（约150秒，尚未录制）

录制前先完成部署、浏览器验证和真实模型配置；未配置时明确介绍本地语法功能，不演成真实AI。

0–20秒：打开工作台，展示基本面、趋势、交集。解释两套独立规则和30只历史研究样本。

20–50秒：输入“PE上限设为20”，查看变更清单，采用到编辑区，再执行。展示新增/移除股票和每只实际值。若真实模型已验证，可换成自由表达并展示它提出的定义。

50–80秒：切趋势，输入“回调”。确认“20日均线附近”，检查-3%至3%的示例，再自行修改范围。添加更宽同向条件演示重复提示；设置矛盾上限演示阻断。

80–110秒：执行趋势，查看排除原因和“只差一项”。打开个股真实日线、MA20/60和原始证据；切交集解释同时满足。

110–135秒：打开数据页，显示真实来源/基准日/公式，明确待接入板块与机构字段不补零。若官方数据已经实际接通，则展示真实取数证据和覆盖率。

135–150秒：比较、保存或导出。说明不预测收益、非全市场与未做事项。
