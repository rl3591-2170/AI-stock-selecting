# 120秒演示脚本（待录制）

录制前必须接入并验证真实模型。若模型尚未接入，只能说明当前演示是规则引擎阶段，不应宣称完整AI主链路。

- 0–15秒：展示产品定位和数据基准日，说明30只研究样本、非全市场、非实时。
- 15–40秒：输入「经营改善、估值合理、走势相对稳定」。展示模型提出的操作化定义与需要确认的问题。强调阈值可修改，不是唯一正确解释。
- 40–55秒：确认条件并执行，展示入选/排除/待验证，说明结果由代码计算。
- 55–75秒：打开一家公司，查看逐条条件、原始字段和来源记录；再查看一项排除原因。
- 75–95秒：修改PE上限，展示实际新增/移除名单。不要保证录制时数量不变，先核对最终快照。
- 95–110秒：选两家公司并排比较，保存策略。
- 110–120秒：展示数据页与局限，说明没有做全市场、回测或收益预测。
