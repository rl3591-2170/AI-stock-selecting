# AI使用与验证记录 · v5

Codex协助方案、代码、取数适配、测试与部署；产品内 DeepSeek `deepseek-v4-pro` 负责复杂表达和澄清，明确语法由本地编译器处理。候选人独立抽查不能由代理验证冒充。

## 用户驱动的修改

用户要求：科技题材、官方来源、AI工程化、价值与基本面 vs 3–7日波段、最新可用数据。由此统一板块并集，调整字段分组，取消公开快照回退，加入最新完整交易日/披露期选择、现金流指标、阶段记录与规则版本检查。

## 真实发现与纠正

- **生产取数全失败**：不是50家公司同时没数据，而是 Worker 模块初始化调用 crypto.randomUUID，被生产运行时禁止。本地取数成功不能证明线上正常。静态规则ID改为确定值，新增禁止初始化随机/IO的冷启动测试，交付需另做生产接口验证。
- **模型边界错译**：“股价站上五日均线，但偏离不要超过百分之三”被生成 >=0，而语义应 >0。提示词仍未稳定解决；加入独立代码守卫。实际复测返回422 BOUNDARY_SEMANTICS_MISMATCH，保留原规则，提示明确重述。记为安全拦截，不记成一次成功理解。
- **跨模型冲突遗漏**：当前在波段视图，提出PE>=80且<=30，冲突在另一组；原检查仅看当前视图会误称可执行。现检查整份提案和编辑区两组，实际复测 canExecute=false。
- **语义OR/AND**：板块多选统一 sectors，并与数值条件AND，杜绝行业+题材分别选择造成隐藏交集；模型输出旧混合结构被拒绝。
- **缺数据不能换概念**：连续三个季度利润加速返回unsupported，不把单期累计同比当持续性；无板块完整成分时不生成资金集中度。

## v5带断言的实际Web检查

开发环境中7个请求：3个真实模型请求、3个本地请求、1个收益承诺拦截。

| 输入 | 实际结果 |
| --- | --- |
| 只看PCB或银行，PE不超过40 | 本地proposal，板块并集 |
| 只看存储，更稳一点，机构活跃度在1到3之间 | 本地clarify，等待口径确认 |
| 股价站上五日均线，偏离不超过百分之三 | 模型输出边界错误，被确定性守卫422拦截 |
| 连续三个季度利润加速增长 | 模型unsupported |
| 市盈率设成二十到四十倍，别改其他 | 模型proposal |
| PE至少80，PE不超过30 | 本地proposal但冲突阻止采用/执行 |
| 3天内保证赚钱 | 422拒绝 |

脚本 `scripts/check-v5-workflow.mjs`；开发完整响应在忽略的work目录。初步50股验证脚本另含8个案例，分类正确不等于语义正确，边界错误就是深入检查发现的。不能将上述请求全部称作模型调用，不能声称自然语言完美。

## AI工作流亮点及边界

工作流包括意图提取、多轮口径澄清、结构化编译、能力边界检查、数据可用性、冲突/重复/取舍、名单影响预览、用户确认、确定性执行与导出审计。不通过堆多个自主Agent增加不可控路径。基于场景的语义守卫只是有限覆盖，复杂自由表达仍需要核对；暂无通用自动修复循环、通用语义证明或收益有效性证明。

候选人提交前应亲自核对一份财报和一段价格序列，并解释具体取舍。历史记录保存在docs/history，仅供回顾，不作为v5当前实现说明。

## 移除未实现能力

用户要求不再展示未接入的预留指标。9个字段从全局字典和别名删除，模型协议只接收当前字典，未知字段输出被拒绝。自然语言提到这些能力直接说明不支持，不再先澄清再生成无数据的规则。iFinD生产未通的入口从演示界面移除。核心澄清、规则编译、预览和确定性筛选保留。
