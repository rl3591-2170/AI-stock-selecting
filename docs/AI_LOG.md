# AI 使用与验证记录

## 当前记录的性质

本文件记录实际发生的开发与验证。候选人尚未开展的独立检查不写成已完成；需要候选人补充自己的取舍、纠正和核验。

## 实际使用

- Codex：阅读题目附件、比较三题范围、协助选题；实现Web界面、确定性筛选引擎、模型服务适配、数据获取脚本与测试。
- 产品内LLM：已实现接口，尚未接入用户供应商，因此没有真实模型运行结果。
- 浏览器自动化：检查真实渲染、修改阈值、查看证据；未用截图代替可运行产品。

## 已发生的修正

1. 初始更倾向个股诊断，用户指出其研究深度风险；重新评估18小时与数据权限后选定规则可验证的选股题。
2. 用户询问为什么需要API；明确模型仅用于意图解析，名单、数字与入选原因由确定性代码产生。
3. 初始Python环境证书链不完整，改用系统curl取得数据，没有关闭TLS验证。
4. 东方财富行情接口首次可用、后续出现空响应；改用腾讯证券前复权行情，并更新来源标注。未用随机数据代替。
5. 初版移动布局隐藏了导航；补充移动导航，让保存策略与数据页仍可返回。
6. 修正保存名称可能与未成功解析的自由输入不一致，改用实际执行规则生成策略名。
7. 负PE不直接通过低估值阈值，标记口径不适用；空值不转换为0。

## 已验证

11项自动测试通过：边界、缺失、负估值、三态AND、规则冲突、非法规则、空结果、名单变化、快照来源与时点、波动率/回撤独立重算、默认名单一致性。

浏览器验证PE上限25→15后，入选12→4，移除8只；证据抽屉展示原始字段及URL。
