# v4 筛选指标与研究池依据

## 指标选择

研究窗口是3–10个交易日，默认趋势条件分工为：MA10近3日变化>0（方向）、价格距MA5为0–6%（位置）、完整日成交量/此前20日均量为1.2–3（量能）、ATR14/收盘价≤6%（波动幅度）。这些数值是可修改示例，未优化历史收益，不是权威机构推荐参数。

“站上”是当前价格与均线的位置关系；“上穿”需要前一日未在线上、当日在线上。近3日上穿后仍可能跌回线下，模板同时检查当前位置。MA20/60仍保留用于较长趋势，不把MA5替代为唯一正确周期。

定义参考：[Fidelity SMA](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/sma)、[ATR](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)、[RSI](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/RSI)。实现采用简单均线、Wilder平滑的ATR/RSI；ATR含跳空，归一为收盘价百分比。RSI衡量自身涨跌动量，不是行业相对收益。不把超买直接解释为做空信号。

基本面默认营收同比≥10%、归母净利率≥5%、扣非利润占归母利润≥80%、PE≤60。分别观察成长、盈利能力、非经常损益依赖与估值约束。归母净利率分母为营业总收入，不冒充合并销售净利率；扣非占比仅正归母利润时适用。跨行业可比性有限，应先明确行业。研发成长观察模板仅营收同比≥20%、市值≥30亿元，允许亏损但不能据此判断便宜或高质量。

财务字段来自公司报告的公开数据接口，扣非定义应与财报核对。[SEC财务报告阅读说明](https://www.investor.gov/introduction-investing/getting-started/researching-investments/how-read-10-k)仅作为报表区分的一般参考，不作为A股阈值或准则依据。净利润现金含量仍未核验供应商单位，不编造现金流质量数据。
